# AdmitFlow AI

AdmitFlow AI organizes college applications, deadlines, essays, and school-specific requirements.

The goal is to help students stay organized while keeping sensitive application data local-first by default.

## Planned Features

- Deadline and checklist tracker.
- Essay version management.
- School-specific requirement summaries.
- AI-assisted review prompts with privacy warnings.

## Quick Start

```powershell
python -m admitflow_ai --sample
```
